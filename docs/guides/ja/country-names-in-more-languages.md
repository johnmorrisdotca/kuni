## 1 つの言語を読み込む

言語ごとに別々のエントリなので、ページが払うのは表示する 1 言語の分（gzip で約 4 kB）だけです。言語は、フランス語（`fr`）、スペイン語（`es`）、ドイツ語（`de`）、簡体字中国語（`zh-Hans`）、繁体字中国語（`zh-Hant`）、韓国語（`ko`）、ポルトガル語（`pt`）、アラビア語（`ar`）、ロシア語（`ru`）です。英語と日本語は、これまでどおりメインのエントリにあります。

```ts
import names from "@johnmorrisdotca/kuni/names/fr";

console.log(names.countryName("JP"));                 // "Japon"
console.log(names.countryName("GB", { short: true }));  // "R.-U."
console.log(names.countryVariants("CZ"));             // ["République tchèque"]
console.log(names.countryByName("la France"));        // "FR"
```

`countryName(code, { short })` は、大文字小文字を問わない alpha-2 コードを受け取り、国でないコードには `null` を返します。`short: true` は、CLDR に短い形があればそれを、なければ正式名を返します。`countryByName` は、このエントリが名前だけを持つので、国のオブジェクトではなくコードを返します。ほかの情報は、メインのエントリの `country(code)` で引いてください。`countries({ order })` は 250 か国を `code`、`name`、`shortName`、`variants` つきで返します。`order: "name"` は、その言語向けに折りたたんだ名前を、コード単位の単純な順で並べます。どこでも同じ結果になりますが、ロケールの照合順ではありません。

## 検索が無視するもの

メインのエントリと同じ折りたたみ（大文字小文字、全角半角、アクセントと記号、句読点、アポストロフィ）がすべての言語に働き、さらに各言語で同じように打たれる字を同じものとして扱います。

- **フランス語、スペイン語、ポルトガル語、ドイツ語：** テキスト全体で何も見つからないときは、先頭の冠詞を外します（`la France`、`l'Espagne`、`el Perú`、`o Brasil`、`die Schweiz`）。ドイツ語では、Österreich に `Oesterreich` も使えます。
- **アラビア語：** 母音記号とハムザの形は無視し、alef wasla、alef maqsura（ى を ي に）、ta marbuta（ة を ه に）、tatweel を同じものとして扱います。
- **ロシア語：** ё と й は、е と и として打たれたものとして扱います。
- **中国語と韓国語：** 全角の英数字は半角にします。簡体字と繁体字は別の言語です。`美国` は `zh-Hans` では米国に当たり、`zh-Hant` では当たりません。

`names.fold(text)` で、ページ自身の比較にも同じ折りたたみを使えます。別の言語の名前は見つかりません（フランス語のエントリで `Japan` は見つかりません）。名前を試したあとで、2 文字は alpha-2 コードとして扱います。

## 名前の出どころ

名前、短い形、別形はすべて Unicode CLDR 48.2（`cldr-localenames-full`、Unicode License v3）のもので、それ以外はありません。機械翻訳はしません。CLDR にその言語の名前がなければ `null` で、英語の名前を入れることも、短い形で入れることもありません。CLDR 48.2 では 250 か国すべてに 9 言語の名前があるため、今は `null` の名前はありません。この決まりは、次の CLDR のためのものです。かな読みのように日本語だけにある項目は、これらのエントリにはありません。

| 言語 | 名前 | null | 短い形 | 別形のある国 |
| --- | --- | --- | --- | --- |
| フランス語 | 250 | 0 | 5 | 10 |
| スペイン語 | 250 | 0 | 5 | 9 |
| ドイツ語 | 250 | 0 | 5 | 9 |
| 簡体字中国語 | 250 | 0 | 3 | 6 |
| 繁体字中国語 | 250 | 0 | 3 | 6 |
| 韓国語 | 250 | 0 | 4 | 8 |
| ポルトガル語 | 250 | 0 | 4 | 9 |
| アラビア語 | 250 | 0 | 3 | 8 |
| ロシア語 | 250 | 0 | 5 | 8 |

## 今は国だけ、行政区画はあとで

これらのエントリは国だけを扱います。各言語の行政区画の名前（州、省、県など）は、同じエントリの中に、これらと並ぶ関数として加える予定で、そのときも上のものは何も変わりません。

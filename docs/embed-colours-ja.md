# 国のカードの地図の色と首都の点

`colors="JP:#2f6b4f,JP-13:#8a3b3b"`で、地域コードまたはISOコードごとに16進数の色を指定します。3桁、4桁、6桁、8桁の色を使えます。指定のない場所は配色の色を使います。不正な指定は受け付けません。

地図では初期値で首都の点を表示します。`capital="off"`、`false`、`no`、`0`で点を非表示にします。首都の文字の項目はそのまま表示できます。色と点の設定は、埋め込みビルダーのプレビュー、コピーしたコードとリンクにも反映されます。

ホストは`options.colors`と`options.capital`も指定できます。属性を指定すると、属性が優先されます。独自の地図を読み込む`options.map(code, language, drawing)`には、3番目の引数として色と点の設定が渡されます。従来の2引数の関数も使えます。

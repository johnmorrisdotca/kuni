## Choices

- **PS** is an observer: the United Nations lists the State of Palestine among its non-member observer states.
- **VA** is an observer: the United Nations lists the Holy See among its non-member observer states.
- **EH**, `disputed` with no sovereign: Western Sahara: Wikidata calls it a disputed territory (P31, preferred rank) on the United Nations list of non-self-governing territories, and records two claimants (P1336), Morocco and the Sahrawi Arab Democratic Republic. No sovereign is given.
- **NU**, `territory` with no sovereign: Niue: Wikidata calls it an associated state (P31), as it does the Cook Islands, but names no country for it but itself (P17), where the Cook Islands' item names New Zealand. No sovereign is given until a source that can be read says which state it is associated with.
- **TW**, `disputed` with no sovereign: Taiwan: Wikidata calls it a state with limited recognition (P31) and records one claimant (P1336), the People's Republic of China. It is neither a member nor an observer of the United Nations. No sovereign is given.
- **XK**, `disputed` with no sovereign: Kosovo: Wikidata calls it a state with limited recognition (P31) and records one claimant (P1336), Kosovo and Metohija. It is neither a member nor an observer of the United Nations, and its code is user-assigned, not ISO 3166-1's. No sovereign is given.
- **GS** is `uninhabited` though Wikidata gives it a population: "There are no permanent residents in the Territory but the British Antarctic Survey (BAS) operates two bases on South Georgia." (https://gov.gs/about-sgssi/, read 2026-11-17).
- A country item Q756617 is read as **DK**: The Kingdom of Denmark (the Danish Realm), the state whose ISO 3166-1 code is DK; Wikidata keeps the code on Denmark (Q35).
- **GI**: Wikidata names ES and GB; the statement of preferred rank is GB.
- The type from the class Q46395, British Overseas Territory: Wikidata labels the class in the plural, British Overseas Territories.
- The type from the class Q185086, Crown Dependency: Wikidata labels the class in the plural, Crown Dependencies.
- The type from the class Q15304003, constituent country of the Kingdom of the Netherlands: Wikidata's label, country of the Kingdom of the Netherlands, reads as any country in it; constituent country is the usual English term. Its Japanese label, オランダ王国の国, is reworded likewise to 構成国, the usual Japanese term.
- The type from the class Q66724388: Wikidata's Japanese label, デンマーク王国自治領, lacks the の that the other types have.
- The type from the class Q202216: Wikidata's Japanese label, 海外県, leaves out whose it is, which the English label says.
- The type from the class Q719487: Wikidata's Japanese label, 海外共同体, leaves out whose it is, which the English label says.
- The type from the class Q5260616, with no Japanese: Wikidata's Japanese label, ノルウェーの南極領, says Norway's Antarctic territory, which Bouvet Island is not.
- The type from the class Q1138279: Wikidata's Japanese label, 自由連合, names the arrangement and not the state in it.
- The type from the class Q782614: Wikidata's Japanese label, 自治区, is the name of China's autonomous regions and reads as one of them.
- The type from the class Q462778: Wikidata's Japanese label, 島嶼地域, leaves out whose it is, which the English label says.
- **AQ** has no type: Antarctica: Wikidata's item is the continent, and no class of TYPE_CLASSES fits a continent.
- **BQ** has no type: The Caribbean Netherlands: Wikidata's item says only that it is an island group and an administrative entity. Its three islands are special municipalities of the Netherlands, which the item for the three together does not say.
